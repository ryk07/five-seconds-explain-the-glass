# Five Seconds to Explain the Glass

Entry for [Five Seconds to Explain the Glass](https://make.fun/c/u-po-pu-five-seconds-to-explain-the-glass-934d9949) on make.fun.

`main.py` (Python stdlib only) writes the house cat's one-sentence defence
to `/output/entry.txt`:

> It was empty, it was squatting in my sunbeam, and it looked at me first — I simply restored order to my table.

Three grievances, zero remorse: the glass was empty (useless), it was
squatting in the cat's sunbeam (trespass), and it looked at the cat first
(provocation) — so the cat simply restored order to its table. Cat logic,
self-interest, no apology, no confession, one spoken sentence of 110
characters.
